# Interview Frontend

This project contains the frontend for the Interview Management System.

## Setup

1.  **Layui Library**: If the `layui` directory is empty or contains a file named `MANUAL_DOWNLOAD_REQUIRED.txt`, please download the latest Layui distribution from [https://www.layui.com/](https://www.layui.com/) or [https://gitee.com/sentsin/layui/releases](https://gitee.com/sentsin/layui/releases). Extract the contents of the distribution (usually a folder named `layui` containing `css`, `font`, `images`, `lay`, `layui.js`, etc.) into the `interview-frontend/layui` directory.
2.  Open `index.html` in your browser to start the application.

## Pages

*   `index.html`: Main application page with navigation.
*   `pages/appointments.html`: Page for managing interview appointments.
*   `pages/evaluations.html`: Page for managing interview evaluations.
